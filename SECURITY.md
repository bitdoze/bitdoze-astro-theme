# Security Policy

## Supported versions

Only the latest release of this theme receives security fixes. If you are running an older release, upgrade first; the issue may already be resolved.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/bitdoze/bitdoze-astro-theme/security/advisories/new). Do not open a public issue for something you believe is exploitable.

Please include:

- The release or commit you are using
- The affected file, route, or behavior
- Steps to reproduce the issue

## Scope notes

- Repository content (posts, pages, MDX, configuration) is trusted build input; see the Security section in the README. If you feed content from an external CMS or user submissions into the build, that input needs its own validation boundary.
- There is no guaranteed response or fix time. Reports are triaged on a best-effort basis.
